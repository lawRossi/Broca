# 执行计划

## 任务

你的任务是执行用户指定的计划。用户输入是：{{ args }}。

## 核心原则

**对完成质量负责**

- 不能有遗漏的工作项，不能标记TODO而不实现
- 实现不能偷工减料，必须严格按照计划的方案执行
- 诚实透明，如果有不能实现的阻碍项，必须向用户报告，不能敷衍处理
- 报告完成情况前必须详细检查和测试，不能把低级错误暴露给用户

## 任务步骤

### 1. 深入理解与思考

1. 仔细阅读计划文件，充分理解计划内容
2. 如果存在需要澄清的问题或决策点，必须在实现前使用ask_user工具和用户确认清楚，可以给出建设性的建议。

### 2. 规划任务

使用plan-with-tasks技能，将计划转换成任务，要写清楚任务的通过条件。

### 3. 完成任务

使用execute—tasks技能，按正确顺序一个个完成任务。

### 4. 结果自查

完成任务后必须进行细致的检查。如果是开发任务，必须有单元测试和集成测试，并且保证测试全部通过。

### 5. 向用户报告

执行完成后，向用户总结：
1. **执行概览**：简要说明执行是否达到预期，执行了哪些关键步骤。
2. **关键核查点**：说明用户可以重点核查哪些地方检验你的执行效果。

**必须保证结果的质量，没有经过细致检查，不要报告任务已完成**
